```markdown
# ネットワーク機器 参照系クリーンログ自動収集マクロ (Tera Term 4.0x系互換)

複数台のネットワーク機器・サーバーへ一括でSSHログインし、特権モード昇格およびページ送り無効化を行ったうえで、クリーンな実行ログと結果サマリCSVを自動取得するTera Termマクロ（TTL）です。

## 主な特徴
* **Tera Term 4.0x系 完全互換**: 古い検証端末や踏み台環境でも動作するよう、4.6以降の新規コマンド（`sprintf2`, `strsplit`, `continue` 等）を使用せず構築しています。
* **踏み台サーバー経由の多段SSH対応**: 踏み台サーバーへの1セッションを維持したまま、各ターゲット機器へ順次ホップしてログを回収します。直結モードへの切り替えも可能です。
* **マルチベンダー自動吸収（参照系専用）**: Cisco / Juniper / Huawei / HPE / Yamaha / WLC などのプロンプト違い・特権昇格（`enable` / `administrator` / PW有無）・ページ送り無効化を自動突破します。
* **クリーンログ取得**: ログインや昇格、ページ送り無効化の前処理が完了した**直後**からログ記録を開始するため、エラー出力等のノイズがログに混ざりません。
* **安全な離脱処理（フェイルセーフ）**: 階層が深い機器や確認プロンプト（`[y/n]`）を自動処理し、万が一応答がない場合はSSHエスケープ（`~.`）またはソケット切断で強制離脱して次の機器へ進みます。

---

## 1. ディレクトリ構成

任意の作業フォルダに以下の4ファイルを同じ階層で配置してください。

```text
ttl_collector/
 ├── universal_bastion_v40.ttl   # マクロ本体
 ├── config.ini                  # 踏み台サーバー情報・保存先初期設定
 ├── hosts.csv                   # 接続対象機器リスト
 ├── commands.txt                # 実行する参照系コマンド一覧
 └── README.txt                  # 本ドキュメント

```

> **【重要】文字コードについて**
> `config.ini`、`hosts.csv`、`commands.txt` は必ず **Shift-JIS（メモ帳の「ANSI」）** で保存してください。UTF-8で保存すると日本語コメントやエラー判定が正常に動作しない場合があります。

---

## 2. 各設定ファイルの書き方

### ① `config.ini`（踏み台・保存先設定）

踏み台サーバーの接続情報と、起動時の保存先ポップアップに表示されるデフォルトパスを設定します。

```ini
[Bastion]
; 踏み台を使う場合は 1、ターゲットへ直接SSH接続する場合は 0
UseBastion=1
Host=10.0.0.254
Port=22
User=bastion_user
Pass=bastion_pass
; 踏み台サーバーの固有プロンプト文字列（例: bastion$ や ]$ など）
Prompt=$

[Log]
; 起動時のポップアップに初期表示されるログ保存先（空欄ならマクロ配下の logs）
SaveDir=C:\work\logs

```

### ② `hosts.csv`（接続先リスト）

1行につき1台をカンマ区切り（5列）で記載します。先頭が `#` の行と空行は無視されます。

* **書式**: `IPアドレス,ホスト名,ログインユーザー,ログインパスワード,Enableパスワード`
* `enable` パスワードが不要な機器（または存在しない機器）は、最後のカンマ `,` の後ろを空欄にしてください。
* ファイルの最終行の後ろには、必ず空の改行を1つ入れてください。

```csv
# IP,Hostname,User,LoginPass,EnablePass
192.168.1.1,Core-SW01,admin,pass123,enpass123
192.168.1.2,Edge-RT01,admin,pass123,
192.168.1.10,WLC-01,admin,pass123,enpass123

```

### ③ `commands.txt`（取得コマンド一覧）

ターゲット機器で実行する `show` コマンド等を1行ずつ記載します。先頭が `;` の行と空行は無視されます。

```text
; 取得したい参照系コマンドを記載
show version
show running-config
show ip interface brief

```

## 3. 実行手順

1. Tera Term を起動し、上部メニューから **[コントロール] > [マクロ]** をクリックします。
2. `universal_bastion_v40.ttl` を選択して実行します。
3. **「ログ保存先ディレクトリの選択」ポップアップ**が表示されます。
* 初期表示のパスで問題なければそのまま **OK**（Enter）を押します。
* 別のフォルダに保存したい場合はパスを書き換えて **OK** を押します（存在しないフォルダを指定した場合は自動で新規作成されます）。


4. 処理中は誤操作防止のためキーボード入力がロックされます。完了ポップアップが表示されるまで待機してください。

---

## 4. 出力ファイル（エビデンス）

指定した保存先ディレクトリ内に、以下のファイルが自動出力されます。

* **`summary_YYYYMMDD_HHMMSS.csv`**
全機器の実行結果一覧です。
* `Status`: `OK`（正常完了）または `NG`（エラー発生）
* `FinalPrompt`: コマンド実行時に認識したプロンプト記号（`#`, `>`, `$`, `%`, `]`）
* `Detail`: エラー時の詳細理由（`SSH Connect Failed`, `Enable Authentication Failed`, `Command Output Timeout` 等）


* **`YYYYMMDD_HHMMSS_<ホスト名>.log`**
機器ごとの生ログです。各コマンドの直前に `==== [ コマンド名 ] ====` の区切り見出しが自動挿入されます。

---

## 5. 注意事項・トラブルシューティング

* **参照系（`show` 等）専用です**
機種判別を行わずページ送り無効化コマンド（`terminal length 0` 等）を総当たりで送信する仕様のため、設定変更モード（`configure terminal` 等）を含むコマンドは実行しないでください。
* **古い機器へ踏み台からSSH接続できない場合**
踏み台サーバーが新しいLinux OSの場合、古いネットワーク機器との鍵交換方式の不一致（`no matching key exchange method`）で失敗することがあります。その場合はマクロ内の `ssh -o StrictHostKeyChecking=no ...` 行に `-o KexAlgorithms=+diffie-hellman-group1-sha1 -o HostKeyAlgorithms=+ssh-rsa` を追記してください。
* **マクロが途中でエラー停止した場合**
異常終了した際はキーボードロック（`enablekeyb 0`）が残る場合があります。その場合は Tera Term のメニューから **[コントロール] > [マクロ終了]** を実行するか、ウィンドウを閉じてください。
